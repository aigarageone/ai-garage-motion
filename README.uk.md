Ти приносиш ідею. **AI Garage дає робочий процес.**

Допоможи своєму AI-агенту пройти весь шлях створення motion-відео: знайти концепцію, спланувати сцени, побудувати вмотивований рух, підготувати звук, перевірити чорновик і видати готовий файл.

Використовуй скіл для продуктових пояснень, запусків, кінетичної типографіки, анімації інтерфейсів, коротких соціальних роликів і візуальних історій. Агент працює англійською або українською; мову, формат і стиль задає бриф.

Рендер може потребувати додаткових програм; платні AI-сервіси й ліцензовані ресурси можуть оплачуватися окремо. Для встановлення скіла не потрібні API-ключі або платний сервіс.

## Встановлення за хвилину

Потрібен сумісний AI-агент для роботи з кодом. Для інсталятора потрібен Python 3.9 або новіший. Git потрібен лише для клонування; також можна вибрати **Code → Download ZIP** і розпакувати репозиторій.

```bash
git clone https://github.com/aigarageone/ai-garage-motion.git
cd ai-garage-motion
```

**Claude Code — для всіх локальних проєктів**

```bash
python3 scripts/install.py --tool claude --scope user
```

**Codex — для всіх локальних проєктів**

```bash
python3 scripts/install.py --tool codex --scope user
```

У Windows заміни `python3` на `py -3`. Інсталятор лише копіює локальні файли: він не встановлює програми рендеру, не налаштовує MCP, не передає дані й не змінює дозволи агента. Наявну версію не перезаписує. Окреме встановлення для одного проєкту, ручне копіювання та оновлення описані в [гіді](docs/GUIDE.uk.md).

Відкрий нову сесію агента у своєму відеопроєкті та виклич скіл:

| Агент | Команда |
| --- | --- |
| Claude Code | `/ai-garage-motion` |
| Codex | `$ai-garage-motion` |

Далі опиши ролик:

> Створи 15-секундне motion-відео про перетворення розрізнених ідей на чіткий план. Тексти українською, 1920×1080, 60 fps, виразна типографіка, музика та синхронний звуковий дизайн. Розроби розкадровку, створи й перевір анімацію, експортуй MP4 і збережи редаговані вихідники. Використовуй авторські абстрактні форми без зовнішніх ресурсів.

## Як відбувається робота

1. **Ідея.** Одне повідомлення та перетворення, що його пояснює.
2. **Режисура.** Різні творчі варіанти й розкадровка з таймінгом.
3. **Анімація.** Узгоджений рух тексту, камери, об'єктів і переходів.
4. **Звук.** Музика та ефекти, пов'язані зі змістовними подіями.
5. **Доопрацювання.** Перегляд чорновика, виправлення дефектів, перевірка фінального файлу.
6. **Здача.** MP4, редаговані вихідники та точний статус перевірок.

Явний бриф важливіший за типові налаштування. Вказуй вертикальний або квадратний формат, 4K, тишу, тривалість чи наявний стек, коли це потрібно. Типова ціль — MP4 1920×1080, 60 fps, H.264 і AAC за наявності звуку.
