# Перше motion-відео з AI Garage

[English](GUIDE.md) · [На головну](../README.uk.md)

Почни з ідеї, яку можна пояснити одним реченням. Встанови скіл, відкрий AI-агента у робочій папці та опиши ролик. AI Garage Motion дає виробничий процес, а агент використовує доступні інструменти коду, анімації, звуку й експорту.

## 1. Вибери спосіб встановлення

### Репозиторій і локальний інсталятор

Потрібен Python 3.9+. Завантаж репозиторій через **Code → Download ZIP**, розпакуй його та відкрий термінал у розпакованій папці. Або виконай:

```bash
git clone https://github.com/aigarageone/ai-garage-motion.git
cd ai-garage-motion
```

Вибери команду для свого агента:

```bash
# Claude Code: для всіх локальних проєктів
python3 scripts/install.py --tool claude --scope user

# Codex: для всіх локальних проєктів
python3 scripts/install.py --tool codex --scope user
```

Для одного наявного проєкту вкажи його шлях:

```bash
python3 scripts/install.py --tool claude --scope project --project /path/to/your-project
python3 scripts/install.py --tool codex --scope project --project /path/to/your-project
```

Достатньо команди для потрібного агента. Якщо працюєш з обома, можна виконати обидві. У Windows заміни `python3` на `py -3`, а шлях — на свій, наприклад `"C:\Projects\motion-demo"`. Додай `--dry-run`, щоб побачити місце встановлення без запису файлів.

### ZIP зі скілом і ручне копіювання

Завантаж [ai-garage-motion.zip](https://github.com/aigarageone/ai-garage-motion/releases/latest/download/ai-garage-motion.zip) і розпакуй. Скопіюй повну папку `ai-garage-motion` до одного з місць:

| Агент | Лише цей проєкт | Усі твої локальні проєкти |
| --- | --- | --- |
| Claude Code | `.claude/skills/ai-garage-motion/` | `~/.claude/skills/ai-garage-motion/` |
| Codex | `.agents/skills/ai-garage-motion/` | `~/.agents/skills/ai-garage-motion/` |

`~` означає домашню папку. Точний кінцевий шлях: `.../ai-garage-motion/SKILL.md`, поруч із `references/`, `scripts/`, `assets/` та `agents/`. Не копіюй лише `SKILL.md` і не залишай подвійну вкладеність `ai-garage-motion/ai-garage-motion/`.

ZIP також можна завантажити в середовище, що підтримує власні skill ZIP. У налаштуваннях Claude web/desktop відкрий **Customize → Skills**, вибери завантаження власної навички й увімкни її. Інтерфейс залежить від версії та акаунта. Локальні папки Claude Code не встановлюють скіл автоматично в Cowork чи хмарні сесії: для них використовуй увімкнені навички акаунта. Доступні інструменти та межі рендеру можуть відрізнятися.

Для іншого агента перевір його офіційну документацію та скопіюй ту саму папку до підтримуваного місця. Пакет не заявляє інтеграції з відеоредактором або сумісності з усіма агентами.

## 2. Перевір, що скіл доступний

Відкрий нову сесію у відеопроєкті. У Claude Code виклич `/ai-garage-motion`; у Codex — `$ai-garage-motion` або вибери скіл зі списку. Напиши:

> Використай AI Garage Motion. Перевір, що можеш прочитати його SKILL.md та робочі модулі, і коротко опиши процес перед початком.

Якщо скіла немає, перевір точний шлях і вкладеність, відкрий нову сесію та переконайся, що правила організації дозволяють власні навички. Актуальні джерела: [Claude Code](https://code.claude.com/docs/en/skills) і [Codex](https://developers.openai.com/codex/skills/). Шляхи перевірено 29 жовтня 2026 року.

Для першого запиту достатньо ідеї, мови, тривалості, формату та побажань до звуку:

```text
Використай AI Garage Motion для 15-секундного відео про перетворення
розрізнених ідей на чіткий план. Текст: «Менше шуму. Більше напрямку».
Українська мова, горизонтальний формат 1920×1080, 60 fps.
Авторські абстрактні форми, виразна типографіка, музика та синхронний
звуковий дизайн. Без голосу. Розроби концепцію й розкадровку з таймінгом,
перевір найскладніший перехід короткою пробою, створи анімацію,
переглянь повний чорновик, виправ суттєві дефекти та передай MP4
з редагованими вихідниками. Використовуй доступні локальні інструменти.
Перед новим платним сервісом або зовнішнім завантаженням запитай дозвіл.
```

Технічний план можна залишити агенту. Якщо потрібен конкретний рушій, стиль, шрифт або наявний проєкт — вкажи це. Додай погоджений логотип, скриншоти й точний текст, коли вони важливі. Якщо хочеш проміжне погодження, прямо попроси показати розкадровку або прев'ю до продовження.

## 4. Збережи робочі документи

За бажанням створи шаблони в новій папці з кореня репозиторію:

```bash
python3 skills/ai-garage-motion/scripts/new_project.py ./my-motion-project --language uk
```

Цей помічник також є у встановленому скілі. Він створює `BRIEF.md`, `STORYBOARD.md`, `REVIEW.md` і `DELIVERY.md`, відмовляється працювати з наявною папкою та не створює медіа чи залежностей. Вихідні ресурси, згенеровані майстри й експорт зберігай відповідно до дискового бюджету проєкту.

## 5. Що означає завершена робота

Очікуй концепцію й розкадровку з таймінгом, пробу головного ризику, повний чорновик із подальшими виправленнями, потрібний відеофайл і редаговані вихідники з командою відтворення. У здачі мають бути фактичні перевірки; сам факт рендеру не означає повного перегляду.

Якщо бракує рендерера, кодера, засобів звуку чи відтворення, агент повинен назвати незавершений крок і передати готові частини. HTML-прев'ю не замінює потрібний MP4. Статичні кадри не доводять плавності руху, а метадані звуку — прослуховування.

Для кодового експорту можуть знадобитися детермінований захват кадрів і кодер, наприклад FFmpeg. Скіл не встановлює їх автоматично та не містить сторонніх медіа. [Модуль експорту](../skills/ai-garage-motion/references/review-and-export.md) пояснює перевірки й приклади команд.
