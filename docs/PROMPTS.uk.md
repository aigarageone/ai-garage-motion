# Почни з відео, яке хочеш створити

[English](PROMPTS.md) · [Гід зі встановлення](GUIDE.uk.md)

Виклич `/ai-garage-motion` у Claude Code або `$ai-garage-motion` у Codex і використай один із запитів. Адаптуй бриф під свою задачу. Результат залежить від доступних агенту інструментів і ресурсів.

## Абстрактна motion-історія

```text
Створи 15-секундне motion-відео про те, як розрізнені ідеї складаються
в чіткий план. Український текст: «Менше шуму. Більше напрямку».
1920×1080, 60 fps. Авторські абстрактні форми й кінетична типографіка,
музика та звуковий дизайн, без голосу. Розроби розкадровку з різними
варіантами сцен, перевір найскладніший перехід, створи й переглянь
повний чорновик, потім експортуй MP4 та збережи редаговані вихідники.
Без зовнішніх медіаресурсів.
```

## Демонстрація реального продукту

```text
Використай надані скриншоти для 20-секундної демонстрації продукту.
Зрозуміло покажи дію та її результат. Збережи фактичний інтерфейс,
підписи й поведінку; не вигадуй функцій або клієнтських результатів.
Українська, 1920×1080, 60 fps, музика й делікатні звуки взаємодії,
без голосу. Узгодь курсор і зміни станів на одному таймлайні.
Перевір та експортуй MP4 з вихідниками. Уточни відсутній важливий факт.
```

## Вертикальний ролик

```text
Створи 12-секундний вертикальний ролик про захист часу для зосередженої
роботи. Текст: «Залиш місце для важливого». 1080×1920, 30 fps,
українською. Виразна читабельна типографіка, просторова композиція
та чітка фінальна пауза. Додай музику й вмотивовані звукові ефекти.
Тримай важливе поза зонами інтерфейсу платформи. Передай перевірений
MP4 і редаговані вихідники.
```

## Робота з референсами

```text
Проаналізуй надані відеореференси. Виділи корисні принципи камери,
темпу, типографіки й переходів та створи оригінальний напрям для мого
15-секундного ролика. Не відтворюй усю послідовність референсів.
Вкажи, що саме вдалося переглянути. Перед повною збіркою покажи
розкадровку й дочекайся мого погодження на цьому етапі.
```

## Доробка чорновика

```text
Перевір цей motion-проєкт і поточний експорт. Збережи погоджені тексти,
формат і стиль. Знайди суттєві проблеми таймінгу, читабельності,
переходів, камери й звуку. Запиши таймкоди, виправ причини та переглянь
оновлений ролик повністю. Збережи попередній експорт. Передай новий
MP4, редаговані зміни й точний статус виконаних та відсутніх перевірок.
```

## Офлайн і без звуку

```text
Створи німе 10-секундне відео з кінетичною типографікою лише доступними
локальними інструментами та авторськими формами. Українська,
1920×1080, 60 fps. Без завантажень, зовнішніх сервісів, голосу,
музики й нових залежностей. Розроби ідею та розкадровку, анімуй,
перевір та експортуй MP4. Якщо потрібного засобу експорту немає,
назви точний незавершений крок і передай редагований проєкт,
не стверджуючи, що MP4 створено.
```
