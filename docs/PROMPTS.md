# Start with the film you want

[Українською](PROMPTS.uk.md) · [Installation guide](GUIDE.md)

Invoke `/ai-garage-motion` in Claude Code or `$ai-garage-motion` in Codex, then use a prompt below. Change the brief to fit your work. Output depends on the tools and resources available to your agent.

## Abstract motion story

```text
Create a 15-second motion video about scattered ideas becoming one clear
plan. English copy: "Less noise. More direction." Landscape 1920×1080,
60 fps. Use original abstract shapes and kinetic typography, music and
sound design, no voice. Develop a timed storyboard with distinct scene
options, test the hardest transition, build and review the full draft,
then export an MP4 and preserve editable source. No external media.
```

## Real product walkthrough

```text
Use the screenshots I provided to create a 20-second product walkthrough.
Show the action and its result clearly. Preserve the actual interface,
labels, and product behavior; do not invent features or customer claims.
English, 1920×1080, 60 fps, music and subtle interaction sounds, no voice.
Plan the cursor and state changes on the same timeline. Review and export
an MP4 with editable source. Ask if a required product fact is missing.
```

## Portrait social clip

```text
Create a 12-second portrait motion clip about protecting focused work.
Copy: "Make room for deep work." 1080×1920, 30 fps, English.
Use bold readable typography, spatial composition, and a clear final hold.
Include music and intentional sound effects. Keep important content away
from platform UI areas. Deliver a reviewed MP4 and editable source.
```

## Work from references

```text
Analyze the reference videos I supplied. Explain the useful principles
of their camera, pacing, type, and transitions, then create an original
15-second direction for my brief. Do not reproduce their full sequence.
State what you could actually inspect. Show the storyboard before full
production and wait for my approval at that checkpoint.
```

## Improve an existing draft

```text
Review this motion project and its current export. Keep the approved copy,
format, and style. Identify substantial issues with timing, reading time,
transitions, camera, or sound. Record timestamps, fix the causes, and review
the revised whole. Preserve the previous export. Deliver a new MP4,
editable changes, and a precise account of completed and missing checks.
```

## Work offline, silently

```text
Create a silent 10-second kinetic typography video using only available
local tools and original shapes. English, 1920×1080, 60 fps.
No downloads, external services, voice, music, or new dependencies.
Choose the concept, storyboard, animate, review, and export an MP4.
If an essential export tool is absent, explain the exact missing step
and deliver the complete editable project without claiming an MP4 exists.
```
