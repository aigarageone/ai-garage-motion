# Storyboard / Розкадровка

## English

Define the film's central transformation in one sentence: what begins, what changes, and why the outcome matters. Use this thread to choose shots and transitions. Avoid applying a favorite visual motif to every brief.

Build a scene table with these fields:

| Field | Record |
| --- | --- |
| Time | Start, end, and the idea the shot communicates |
| Action | Initial state, trigger, movement, reaction, resulting state |
| Composition | Focal point, foreground/background, light, and material |
| Copy | Exact words, animation, and readable hold |
| Camera | Framing, path, target, speed, and focus |
| Transition | What connects this shot to the shots before and after it |
| Sound | Music accent, voice, SFX, or explicit silence |
| Risk | Hardest feature and a practical preview to validate it |

For each scene, sketch 3–5 short alternative directions. Select for the whole film: a good isolated shot can still interrupt the story. Share the selected direction and a short production reason.

Design both sides of a transition together. For a match cut, align silhouette, screen position, scale, orientation, and movement. For a mask reveal, make the next scene genuinely appear through the mask. If the film shares a continuous location, maintain consistent geometry, lighting, and motion.

Allocate enough time for the exact text to be read during normal playback. Protect the opening message and final action. Prototype the most uncertain moment at a representative quality before committing to the full render. A storyboard is a working plan; it does not create an extra approval gate unless the user requested one.

## Українською

Опиши головне перетворення одним реченням: із чого починається історія, що змінюється і чому результат важливий. Ця нитка визначає плани та переходи. Не підставляй у кожен бриф один улюблений візуальний прийом.

Для кожної сцени зафіксуй:

| Поле | Що записати |
| --- | --- |
| Час | Початок, кінець і головна думка плану |
| Дія | Початковий стан, поштовх, рух, реакція, результат |
| Композиція | Акцент, передній і задній плани, світло, матеріал |
| Текст | Точні слова, анімація та час для читання |
| Камера | Крупність, траєкторія, ціль, швидкість і фокус |
| Перехід | Зв'язок із попереднім і наступним планом |
| Звук | Акцент музики, голос, SFX або явна тиша |
| Ризик | Найскладніша властивість і коротка проба для її перевірки |

Запропонуй 3–5 коротких творчих варіантів кожної сцени. Вибирай із погляду цілого: вдалий окремий кадр може порушувати історію. Покажи обране рішення та стислу практичну причину.

Проєктуй обидва боки переходу разом. Для match cut узгодь силует, позицію, масштаб, орієнтацію та рух. Для маски наступна сцена має справді відкриватися крізь неї. У спільній локації зберігай геометрію, світло та безперервність руху.

Заклади час на читання точного тексту під час звичайного перегляду. Захисти перше повідомлення й завершальну дію. До повного рендеру перевір найризикованіший момент у показовій якості. Розкадровка є робочим планом; окреме погодження потрібне лише тоді, коли його просив користувач.
