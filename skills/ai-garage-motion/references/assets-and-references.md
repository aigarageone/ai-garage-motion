# Assets & references / Ресурси й референси

## English

When references are supplied, identify what each contributes: camera language, pacing, type, materials, transitions, or sound. Combine compatible principles into an original direction. Do not claim a reference was watched if only a still or description was available. Do not copy an entire sequence merely by changing the brand name.

For a recurring character or object, establish a canonical reference set and invariant traits. Reuse that set for each edit or pose; chaining only the latest generated image accumulates drift. Check silhouette, anatomy, proportions, details, light, contact, camera, and anchor points. A sequence of discrete poses is not continuous rotation. One image's parallax cannot reveal unseen geometry reliably.

For transparency, verify the actual alpha channel and inspect edges on light and dark backgrounds. A checkerboard drawn into an image is not transparency. Check halos, premultiplication, cropping, and resampling after export.

Choose 3D assets for the actual renderer and shot. Inspect scale, axes, pivots, topology, materials, textures, rig, animation clips, and licenses. Use articulated geometry for meaningful joints; moving a rigid object cannot substitute for a bend. Validate shadows, ground contact, intersections, and the intended close-up before full production.

Record the author, source URL, asset/version, license, required attribution, and modifications for external media. Free download does not imply redistribution rights. Keep third-party assets out of a public source package unless their licenses permit that specific distribution. Verify provider access, pricing, and output rights when selecting a service; this skill bundles no provider accounts or third-party media.

## Українською

Для кожного референсу визнач внесок: камера, темп, типографіка, матеріали, переходи чи звук. Поєднай сумісні принципи в оригінальний напрям. Не стверджуй, що переглянув відео, якщо доступний лише кадр або опис. Не копіюй усю послідовність зі зміненою назвою бренду.

Для повторюваного героя чи об'єкта зафіксуй канонічні референси та незмінні ознаки. Використовуй той самий набір для кожної правки або пози; ланцюжок лише з останніх генерацій накопичує відхилення. Перевір силует, анатомію, пропорції, деталі, світло, контакт, камеру й опорні точки. Серія поз не є безперервним обертанням. Паралакс одного зображення не відтворює приховану геометрію достовірно.

Для прозорості перевір справжній alpha-канал і краї на світлому та темному фонах. Намальована шахівниця не є прозорістю. Після експорту перевір ореоли, premultiplication, обрізання та масштабування.

Обирай 3D-ресурс під фактичний рушій і план. Перевір масштаб, осі, pivots, геометрію, матеріали, текстури, риг, анімаційні кліпи й ліцензію. Для суглобів потрібна відповідна геометрія: переміщення жорсткого об'єкта не замінює згинання. До повної збірки перевір тіні, контакт, перетини та потрібний крупний план.

Записуй автора, URL джерела, ресурс/версію, ліцензію, потрібну атрибуцію та зміни. Безкоштовне завантаження не означає право на розповсюдження. Не додавай сторонні ресурси до публічного пакета без відповідного дозволу ліцензії. Доступ, ціни та права сервісу перевіряй під час вибору; скіл не містить акаунтів або сторонніх медіафайлів.
